# 四种基础派生

用户已选择四种基础派生。右键按下直接横扫，移除长按投枪瞬移输入与蓄力提示。

- 斜刺 → 右键：挑斩，自低向高划过，0.30 秒生效，0.48 秒可衔接，总长 0.78 秒，伤害 34。
- 横扫 → 左键：进步直刺，短距离向前踏进，0.26 秒生效，0.43 秒可衔接，总长 0.72 秒，伤害 32。
- 回拉 → 右键：下劈，自高向下压落，0.38 秒生效，0.57 秒可衔接，总长 0.92 秒，伤害 46。
- 闪避 → 左键：侧身突刺，闪避末段转入侧身低位刺击，0.24 秒生效，0.42 秒可衔接，总长 0.70 秒，伤害 30。

前三种沿用前置动作的衔接窗口与提前 0.18 秒预输入。闪避在 0.38 秒后可接突刺，保留前段免伤且突刺自身不增加免伤。离开前置动作后不会无条件释放派生。普通派生不消耗或生成枪意；成功格挡→Ctrl 大范围横扫命中获取枪意保持不变。Ctrl/Alt 组合键优先，不被基础派生替换。每招使用独立武器曲线、躯干及支撑腿姿态，短位移经过正常角色碰撞，不使用瞬移或扩大扇形判定。

验证输入路由、过早/预输入/合法衔接、取消与受击、每段只结算一次、无投枪长按、独立接触轨迹，并采样实机画面。模型品质和真人手感仍需试玩验收。
